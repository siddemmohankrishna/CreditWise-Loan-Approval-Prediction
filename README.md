# CreditWise: Loan Approval Prediction using Machine Learning

## Overview

CreditWise is a machine learning project that predicts whether a loan application is likely to be approved based on applicant information such as income, credit score, debt-to-income ratio, employment status, and loan amount.

The project demonstrates the complete data science workflow including data preprocessing, exploratory data analysis (EDA), feature engineering, model building, and performance evaluation.

## Dataset

The dataset contains loan applicant information including:

* Applicant Income
* Credit Score
* Debt-to-Income Ratio (DTI)
* Employment Status
* Education Level
* Loan Amount
* Loan Approval Status

## Project Workflow

### 1. Data Preprocessing

* Missing value handling
* Feature encoding
* Data cleaning
* Feature scaling using StandardScaler

### 2. Exploratory Data Analysis (EDA)

* Distribution analysis
* Correlation analysis
* Loan approval trends
* Feature relationship visualization

### 3. Machine Learning Models

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes

### 4. Model Evaluation

* Accuracy Score
* Confusion Matrix
* Classification Report
